## The entry

`main.py` (Python 3, stdlib only, no network) writes the entry (142 characters) to `/output/entry.txt`:

> At 6:40 a.m. the lift doors opened on floor three and a stranger's violin practice slipped out, as if the building had been humming to itself.

The program is fully deterministic: the same text on every run. It self-checks the length gate before writing it.

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
